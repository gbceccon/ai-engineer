# Phases — study notes & exercises

One folder per phase: `phase-0-setup/`, `phase-1-python-ai/`, … `phase-7-market/`.

Each phase folder contains:
- `notes.md` — key concepts in my own words (Feynman technique, in English)
- `exercises/` — small notebooks/scripts from courses
- `gate.md` — evidence the exit gate was met (link to release + benchmark)

**Gate rule:** don't start phase N+1 until phase N's `gate.md` links to a tagged release.
